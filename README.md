# KAPRI-LAB

Автоматическая лаборатория проверки проекта [К.А.П.Р.И.](https://github.com/loslam-del/K.A.P.R.I).

## Что делает первая версия

- Забирает исходный код К.А.П.Р.И. в отдельную папку.
- Запускает Python-проверки самого отчётчика.
- Пытается собрать Android-проект и выполнить unit-тесты.
- Сохраняет отчёт и APK (если сборка прошла) как GitHub Actions artifacts.
- Запускается вручную, при изменениях в лаборатории и по расписанию.

## Важно

Успешная сборка не доказывает, что приложение правильно работает на реальном телефоне или в Geometry Dash. После сборки нужна ручная проверка на устройстве.

Первая версия работает без AI-ключей и не меняет исходный проект автоматически. Никаких автоматических слияний или публикаций APK.

## Запуск

Открой вкладку **Actions**, выбери **KAPRI Lab Check** и нажми **Run workflow**. Результаты появятся в запуске workflow: отчёт и, если сборка удалась, APK.

## Совместимость обновлений Android

Лаборатория проверяет, что `applicationId` К.А.П.Р.И. не изменился. Это только одна часть совместимости: Android также требует совместимую подпись APK. Текущая сборка `assembleDebug` на новом GitHub runner может получать другой debug-сертификат при каждом запуске, поэтому Android может отклонять APK как конфликтующий. Перед публикацией обновлений настрой постоянную подпись; подробности и ограничения миграции описаны в [руководстве](docs/android-updates.md).

## Расширение с AI

AI-проверку можно добавить позже через GitHub Actions Secret. Никогда не добавляй API-ключ в код, README, issue или чат. Предложения AI должны проходить проверку человеком до применения.
