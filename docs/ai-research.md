# Ночной совет ИИ KAPRI-LAB

## Что делает
Ручной workflow **KAPRI Night AI Council** собирает ограниченную выборку текстовых файлов K.A.P.R.I. и запускает многораундовое обсуждение двух отдельных API-моделей:
1. Gemini готовит первоначальный технический разбор.
2. Модель OpenAI проверяет идеи, спорит с предположениями и предлагает альтернативы.
3. Gemini отвечает на критику.
4. OpenAI подводит итог: согласованные решения, разногласия и приоритетный план.

Итог на русском появляется в GitHub Actions Job Summary и в artifact `kapri-ai-council` (хранится 30 дней).

## Настройка секретов
В KAPRI-LAB открой Settings → Secrets and variables → Actions → New repository secret и создай:
- `GEMINI_API_KEY` — ключ Gemini API.
- `OPENAI_API_KEY` — ключ OpenAI API.

Ключи вводи только в GitHub Secrets. Не отправляй их в чат, не добавляй в репозиторий и не печатай в логах. API обоих провайдеров может тарифицироваться; проверь лимиты и расходы перед запуском.

Необязательные Variables:
- `GEMINI_MODEL` — по умолчанию `gemini-2.5-flash`.
- `OPENAI_MODEL` — по умолчанию `gpt-4.1-mini`.

## Запуск
1. Открой Actions → KAPRI Night AI Council.
2. Нажми Run workflow.
3. Укажи тему или оставь стандартную.
4. После завершения открой Summary или скачай artifact `kapri-ai-council`.

## Важно
Это два отдельных API-агента, а не прямое подключение к текущему ChatGPT-чату и не личный аккаунт ChatGPT. Они обмениваются текстом через координатор KAPRI-LAB в рамках одного запуска. Чтобы я в этом чате разобрал их выводы, принеси сюда отчёт.

Совет работает только на чтение: не меняет исходники, не создаёт PR, не публикует APK и не управляет телефоном. Он анализирует ограниченную выборку исходников; выводы требуют проверки. Содержимое репозитория отправляется выбранным API-провайдерам для обработки.
