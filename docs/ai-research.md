# Ночной ИИ-исследователь KAPRI-LAB

## Что делает
Ручной запуск workflow KAPRI Night AI Research читает ограниченную выборку текстовых файлов К.А.П.Р.И. и отправляет её в Gemini API. Отчёт на русском сохраняется как artifact kapri-ai-research и добавляется в Job Summary.

Workflow только анализирует: не меняет исходники, не создаёт PR, не публикует APK и не управляет телефоном.

## Однократная настройка
1. Открой KAPRI-LAB → Settings → Secrets and variables → Actions.
2. В Secrets создай GEMINI_API_KEY.
3. Вставь ключ прямо в GitHub Secrets. Не отправляй его в чат и не добавляй в файлы.
4. Необязательно: в Variables задай GEMINI_MODEL. По умолчанию gemini-2.5-flash.

Без secret запуск завершится понятной ошибкой.

## Запуск
1. Открой Actions → KAPRI Night AI Research.
2. Нажми Run workflow.
3. Оставь стандартный фокус или задай свой.
4. После завершения открой Summary или скачай artifact kapri-ai-research.

## Ограничения
Это отдельный вызов Gemini API, а не непрерывный диалог Gemini с ChatGPT. Анализируется ограниченная выборка текстовых файлов; выводы нужно сверять с исходниками. Код не меняется автоматически. Использование API может тарифицироваться провайдером.
